# パソコンのデータを NAS にバックアップする（売却前用）

アプリや Windows/macOS 本体は含めず、**自分のデータ（ユーザーフォルダ）だけ**を NAS にコピーします。

| OS | ファイル | コピー対象 |
|---|---|---|
| Windows | `windows_backup_to_nas.bat` | `C:\Users\<自分>`（ドキュメント・写真・デスクトップ・ダウンロード等） |
| Mac | `mac_backup_to_nas.sh` | `~/`（書類・写真・デスクトップ・ダウンロード等） |

アプリの設定フォルダ（Windows の `AppData`、Mac の `Library`）は対象外です。

## 手順
1. NAS にバックアップ用の共有フォルダを作る（例: `backup`）
2. スクリプト冒頭の `NAS` / `NAS_DIR` を自分の NAS に合わせて書き換える
3. 実行する
   - **Windows**: `windows_backup_to_nas.bat` をダブルクリック
   - **Mac**: Finder で NAS に接続してから、ターミナルで `bash mac_backup_to_nas.sh`

## 売却前のチェックリスト
- [ ] NAS 上でファイルが開けるか、いくつか確認した
- [ ] `C:\Users` 以外（D ドライブなど）に保存したデータがないか確認した
- [ ] ブラウザのパスワード・ブックマークは、ブラウザの同期またはエクスポートで保存した
- [ ] メールソフトのデータ（Outlook の .pst など）を保存した
- [ ] Microsoft / Apple アカウントからサインアウトし、ライセンスの認証を解除した
- [ ] 初期化した（Windows:「この PC をリセット」→「すべて削除」→「ドライブを完全にクリーンアップ」／Mac:「すべてのコンテンツと設定を消去」）
