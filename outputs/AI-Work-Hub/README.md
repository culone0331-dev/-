# AI Work Hub

ChatGPT・Codex・Claude・Claude Code・ローカルLLMを行き来しても、案件ごとの目的・原文・判断・未確認点・回答を失わずに済む共有作業台帳です。

仕様の詳細は [`AI_WORK_HUB_SHARED_WORKSPACE_SPEC.md`](./AI_WORK_HUB_SHARED_WORKSPACE_SPEC.md) を参照してください。依存ライブラリなし（Python標準ライブラリのみ）で動きます。

## 使い方

```bash
cd outputs/AI-Work-Hub
python3 server.py
# もしくはポートを変える場合
AI_WORK_HUB_PORT=8787 python3 server.py
```

起動後、`http://<このPCのIP>:8787/` をスマホなど同じネットワーク内の端末から開きます。

## 基本の流れ

1. 受信箱の入力欄に話しかける／書く →「これを残す（新しい案件）」で新しい案件が始まる
   （外部AIで話した内容が起点の場合は「＋ 他のAIから取り込む」で、原文のまま貼り付ける）
2. 案件画面には「目的」「現在地」「最後の原文」「最後のAI回答」だけを最初に表示
3. 「→ Codexへ渡す」「→ Claude Codeへ渡す」「→ ChatGPTへ渡す」をタップすると、
   該当アプリを開くのと引き継ぎパッケージのコピーが一度に終わる（ワンタップ）
   - Codexは固定の起動URLがないため、コピーだけで完了する（未登録でもエラーにしない）
   - コピーに失敗しても、画面下の欄を長押しすれば手動コピーできる
4. 開いた先に貼り付けて送信し、返ってきた回答は「他のAIから取り込む」と同じ要領で
   案件へ貼り戻す（出所と原文を保存し、要約し直さない）
5. ローカルLLM（culone-server / AI2）は「→ ◯◯で確認」で直接呼び出せる
   （コピー・貼り付け不要。接続先未設定の場合は「設定」で登録するよう案内する）
   - 依頼は待機列へ入り、画面を閉じても処理を続ける
   - 同じ推論機ではメモリ競合を避けるため一件ずつ、culone-serverとAI2には並行して依頼できる
   - 案件画面で「待機中・確認中・完了・失敗」と回答の保存を確認できる

「決まったこと」「未確認点」「全履歴」「引き継ぎ履歴（版番号つき）」は、案件画面の
「詳細を見る」から確認できます（最初の画面には出しません）。

外部AIへの自動送信は行いません（各サービスが自動投稿APIを提供していないため）。

## Androidの共有メニューから直接送る

ChatGPTアプリなどで文章を選んで共有すると、AI Work Hubが共有先の候補に出るようにできます
（Web Share Target。コピー→アプリ切り替え→貼り付け、が不要になります）。

1. スマホのChromeでAI Work Hubを開く（`http://<このPCのIP>:8787/`）
2. Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選ぶ
3. 以後、ChatGPTなどで文章を選択して共有すると「AI Work Hub」が候補に出る
4. 共有すると、「他のAIから取り込む」画面が開き、共有した内容が自動で入力欄に入る
   （送り元AIは自動判定できないため、初期値はChatGPTにしています。違う場合は選び直してください）

## 設定

「⚙ 設定」画面で、ChatGPT / Claude Code の開き先URLと、Codex の開き先URL（任意）を登録します。
ローカルLLMの接続先URL・モデル名も同じ画面から登録します（コード側に決め打ちの値は入れていません）。

## データの保存先

`data/store.json`（Git管理外）に、案件・原文・AI回答・引き継ぎ履歴・設定をまとめて保存します。
culone-server上で稼働している旧版（SQLite保存）とは完全に別のファイルで、
このリポジトリの変更が旧版のデータに触れることはありません。
移行手順は `CLAUDE_CODE_HANDOFF.md` を参照してください。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `server.py` | APIサーバー（案件の保存・引き継ぎパッケージ生成・ローカルLLM呼び出し） |
| `index.html` / `app.js` / `style.css` | フロントエンド（案件中心のスマホ向けUI） |
| `data/store.json` | 実行時に作成される保存データ（Git管理外） |
| `AI_WORK_HUB_SHARED_WORKSPACE_SPEC.md` | 共有作業台帳としての仕様書（Codex作成） |
| `CLAUDE_CODE_HANDOFF.md` | Claude Code向けの引き継ぎメモ |
| `CODEX_HANDOFF.md` / `CODEX_REVIEW_TO_CLAUDE.md` | CodexとClaude Code間の引き継ぎ・レビュー記録 |

## Codex / Claude Code との共同作業

- 基準ブランチ・ブランチ命名は、このリポジトリ直下の `CLAUDE_CODE_DESIGN_AND_REVIEW.md`（他プロジェクト向け）と同様に、
  Claude Codeは `claude/` で始まる作業ブランチ、Codexは `codex/` で始まる作業ブランチを使います。
- 変更後は `python3 server.py` を起動し、受信箱→案件を始める（または取り込む）→
  決まったこと・未確認点の追加→渡す、の一連の流れを手動確認してください。
- 保存データの構造（`data/store.json`）を変える場合は、先に相談してください。
